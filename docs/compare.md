# Сравнение с другими инструментами

Для MAX есть другие открытые инструменты. Эта страница ставит `max` рядом с пятью из них и сравнивает по задачам:
что вы можете сделать. По таблице видно, какой инструмент подходит под вашу работу. Отметки для `max` проверены по его
коду (версия 0.71.0). Отметки для остальных взяты из документации и исходного кода их проектов, на 24 октября 2026.
Инструмент может уметь больше, чем описано в его документации.

Инструменты:

- **max**: этот инструмент. Командная строка и MCP-сервер для вашего аккаунта MAX и для ваших ботов.
- **[PyMax](https://github.com/MaxApiTeam/PyMax)**: библиотека на Python для личного аккаунта.
- **[tsmax](https://github.com/sibstark/tsmax)** (`@bruch/max-client`): библиотека на TypeScript для Bun, личный
  аккаунт.
- **[max-mcp](https://github.com/renosaza/max-mcp)**: MCP-сервер на PyMax, личный аккаунт, 8 инструментов.
- **[mcp-max-messenger](https://github.com/woyaxnini/mcp-max-messenger)**: MCP-сервер на официальном Bot API,
  21 инструмент.
- **[Bot API MAX](https://dev.max.ru/docs-api)** и его SDK: единственный официальный программный доступ. Работает
  от имени бота, не вашего аккаунта.

✅ да · 🟡 частично · ❌ нет · ➖ не описано в документации

Личный аккаунт работает через неофициальный протокол MAX. Бот работает через официальный Bot API. Из инструментов
выше официальный путь есть только у mcp-max-messenger и Bot API.

## Что можно сделать

В таблицах: **max**, [PyMax](https://github.com/MaxApiTeam/PyMax), [tsmax](https://github.com/sibstark/tsmax),
[max-mcp](https://github.com/renosaza/max-mcp),
[mcp-max-messenger](https://github.com/woyaxnini/mcp-max-messenger), [Bot API](https://dev.max.ru/docs-api).

### Ответить и отправить

| Задача | max | PyMax | tsmax | max-mcp | mcp-max-messenger | Bot API |
|---|:-:|:-:|:-:|:-:|:-:|:-:|
| Ответить, исправить, удалить, переслать сообщение | ✅ | ✅ | ✅ | 🟡 | 🟡 | ✅ |
| Отправить фото или файл | ✅ | ✅ | ✅ | ✅ | 🟡 | ✅ |
| Отправить несколько фото одним сообщением | 🟡 | ✅ | ✅ | ❌ | ➖ | ➖ |

`max` отправляет в одном сообщении одно вложение из `--file` и одно из `--photo`. Альбома из многих фото пока нет.
Видео и файл уходят только отдельным сообщением. У max-mcp нет изменения и удаления сообщений. У mcp-max-messenger нет
пересылки, а файлы уходят по ссылке.

| Задача | max | PyMax | tsmax | max-mcp | mcp-max-messenger | Bot API |
|---|:-:|:-:|:-:|:-:|:-:|:-:|

У max-mcp поиск простой: по подстроке, и каждый вызов читает историю одного чата. У PyMax поиск по серверу назван в
списке кодов операций, а в документации его нет. Поиск по картинкам по тому, что на них видно, `max` умеет с моделью на
вашем компьютере. Её нужно включить отдельно.

### Группы и каналы

| Задача | max | PyMax | tsmax | max-mcp | mcp-max-messenger | Bot API |
|---|:-:|:-:|:-:|:-:|:-:|:-:|
| Создать группу, добавить людей, назначить админов | ✅ | ✅ | 🟡 | ❌ | 🟡 | 🟡 |
| Посмотреть заявки на вступление, принять или отклонить | ✅ | ✅ | ✅ | ❌ | ➖ | ➖ |
| Обзор группы или канала за период: сообщения, активные люди, новички, ушедшие | ✅ | ❌ | ❌ | 🟡 | ❌ | ➖ |
| Комментарии под постами канала | 🟡 | ➖ | ❌ | ❌ | ❌ | ✅ |

У mcp-max-messenger и Bot API группы только те, где есть бот. У tsmax нет назначения админов. Обзор в `max` считается
по локальной копии, вход и выход людей `max` спрашивает у MAX. У max-mcp есть реакции и статистика постов канала, но не
обзор группы. Комментарии под постами `max` умеет только от имени бота, в личном аккаунте их нет.

### Агенты и безопасность

Здесь PyMax, tsmax и Bot API получают ➖ там, где защиту должен написать автор программы: это библиотеки, готовых
настроек у них нет.

| Задача | max | PyMax | tsmax | max-mcp | mcp-max-messenger | Bot API |
|---|:-:|:-:|:-:|:-:|:-:|:-:|
| Агент читает и пишет в MAX через MCP | ✅ | ❌ | ❌ | ✅ | ✅ | ❌ |
| Агент с терминалом работает без MCP: навык объясняет команды | ✅ | ❌ | ❌ | 🟡 | ❌ | ❌ |
| Агент только читает, пока вы не разрешите запись | ✅ | ➖ | ➖ | ❌ | ❌ | ➖ |
| Спрашивать вас перед каждой отправкой | ✅ | ➖ | ➖ | ❌ | ❌ | ➖ |
| Разрешить отправку только в список чатов | ✅ | ➖ | ➖ | ❌ | ❌ | ➖ |
| Ограничить число отправок в час | ✅ | ➖ | ➖ | ❌ | ❌ | ➖ |
| Повтор отправки не создаёт второе сообщение | ✅ | ➖ | ➖ | ❌ | ❌ | ➖ |
| Токен лежит в ключнице системы, а не в файле | ✅ | ❌ | ❌ | 🟡 | 🟡 | ➖ |

MCP-сервер `max` отдаёт агенту три инструмента: поиск команды, чтение и запись. Через них доступна большая часть
команд, записи входят. Права профиля действуют и для MCP. Вход, настройки, расписания, автоответы, резервные копии и
удаление чатов остаются только в командной строке. Для ответа агент пишет черновик и отправляет его только после вашего
«да» на этот текст. Лимит по умолчанию: 30 отправок в час на профиль, в ошибке сказано, когда можно снова. У max-mcp
одно ограничение: список разрешённых папок для файлов. У max-mcp токен лежит в файле с правами 0600, у
mcp-max-messenger это переменная окружения `MAX_TOKEN`. У PyMax и tsmax токен в файле сессии `session.db`.

## Установка и лицензия

| | max | PyMax | tsmax | max-mcp | mcp-max-messenger | Bot API |
|---|---|---|---|---|---|---|
| Установка | npm, pnpm, Bun | библиотека Python | библиотека, только Bun | git, `uv` и скрипт входа | `npx` | SDK |
| MCP | stdio и HTTP, для агентов в браузере | нет | нет | stdio | stdio и HTTP | нет |
| Лицензия | Apache-2.0 | MIT | MIT | MIT | MIT с Commons Clause | бесплатно, только для проверенных организаций, ИП и самозанятых |

`max` нужен Node 22.16+ или 24+, либо Bun 1.3+. Установщика без Node пока нет. Агент в браузере, который управляет
`web.max.ru`, работает через интерфейс и вход в браузере. `max` обращается к MAX напрямую из командной строки, а
браузер нужен ему только для входа по QR-коду или SMS.

## Когда лучше другой инструмент

- **Приложение MAX** ([web.max.ru](https://web.max.ru), десктоп, телефон): вам нужны звонки, кружки, статусы набора
  текста и никакой настройки. Приложение официальное, и правила MAX к нему не придираются.
- **PyMax или tsmax**: вы пишете свою программу и вам нужен альбом из многих фото или файл вместе с фото в одном
  сообщении (tsmax). У PyMax есть и кружки.
- **Bot API и mcp-max-messenger**: вы делаете официального бота для организации или нужен MCP-сервер только для бота,
  который запускается одной командой `npx`. Это единственный официальный путь, и он не нарушает правил MAX. Комментарии
  под постами канала там тоже есть.
- **Режим без копии на диске**: пока его нет в `max`. Библиотеки и max-mcp не хранят текст сообщений.
