# Сравнение с другими инструментами

Для MAX есть другие открытые инструменты. Эта страница ставит `max` рядом с шестью из них. По таблице видно,
что умеет каждый, и можно выбрать подходящий под задачу. Отметки для `max` проверены по его коду
(версия 0.71.0). Отметки для остальных взяты из документации и исходного кода их проектов, на 23 октября 2026.
Инструмент может уметь больше, чем описано в его документации.

Инструменты:

- **max**: этот инструмент. Командная строка и MCP-сервер для вашего аккаунта MAX и для ваших ботов, с локальной
  копией переписки.
- **[PyMax](https://github.com/MaxApiTeam/PyMax)**: библиотека на Python для личного аккаунта.
- **[tsmax](https://github.com/sibstark/tsmax)** (`@bruch/max-client`): библиотека на TypeScript для Bun, личный аккаунт.
- **[vkmax](https://github.com/nsdkinx/vkmax)**: библиотека на Python для личного аккаунта, на уровне кодов операций.
- **[max-mcp](https://github.com/renosaza/max-mcp)**: MCP-сервер на PyMax, личный аккаунт, 8 инструментов.
- **[mcp-max-messenger](https://github.com/woyaxnini/mcp-max-messenger)**: MCP-сервер на официальном Bot API,
  21 инструмент.
- **[Bot API MAX](https://dev.max.ru/docs-api)** и его SDK
  ([TypeScript](https://github.com/max-messenger/max-bot-api-client-ts),
  [Go](https://github.com/max-messenger/max-bot-api-client-go)): единственный официальный программный доступ.
  Работает от имени бота, не вашего аккаунта.

✅ да · 🟡 частично · ❌ нет · ➖ не применимо или не описано в документации

Личный аккаунт работает через неофициальный протокол MAX. Бот работает через официальный Bot API. Из
инструментов выше официальный путь есть только у mcp-max-messenger и Bot API.

## Возможности

В таблицах: **max**, [PyMax](https://github.com/MaxApiTeam/PyMax), [tsmax](https://github.com/sibstark/tsmax),
[vkmax](https://github.com/nsdkinx/vkmax), [max-mcp](https://github.com/renosaza/max-mcp),
[mcp-max-messenger](https://github.com/woyaxnini/mcp-max-messenger), [Bot API](https://dev.max.ru/docs-api).

MCP-сервер `max` отдаёт агенту три инструмента: поиск команды, чтение и запись. Через них доступны 247 из 350
команд, записи входят. Права профиля действуют и для MCP. Вход, настройки, расписания, автоответы, резервные
копии и удаление чатов остаются только в командной строке. У max-mcp ограничение одно: список разрешённых папок
для файлов. У PyMax, tsmax и vkmax это библиотеки, лимиты в них пишет сам автор программы.

## Когда лучше другой инструмент

- **Приложение MAX** ([web.max.ru](https://web.max.ru), десктоп, телефон): вам нужны звонки, кружки, статусы набора
  текста и никакой настройки. Приложение официальное, и правила MAX к нему не придираются.
- **PyMax**: вы пишете свою программу на Python и вам нужны кружки, набор текста и смена облачного пароля уже сейчас.
- **tsmax**: вы пишете программу на TypeScript под Bun и хотите события набора текста.
- **Bot API и его SDK**: вы делаете официального бота для организации. Это единственный официальный путь, и он не
  нарушает правил MAX.
- **mcp-max-messenger**: вам нужен MCP-сервер для бота, который запускается одной командой `npx`.
- **max-mcp**: вам нужен небольшой MCP-сервер на PyMax, а локальная копия и лимиты не нужны.
- **Режим без копии на диске**: пока его нет в `max`. Библиотеки и max-mcp не хранят текст сообщений.
