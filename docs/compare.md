# Сравнение с другими инструментами

Эта страница нужна, когда вы выбираете инструмент для MAX и хотите увидеть, чем `max` отличается от других, по задачам. Само сравнение живёт на сайте wirecat.dev, потому что оно меняется, когда меняются другие инструменты, а не когда выходит релиз `max`.

Читайте сравнение: [`max` и другие инструменты MAX](https://wirecat.dev/ru/docs/max/compare).
