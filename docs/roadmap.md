# Дорожная карта

На этой странице — то, что планируется в `max` и чего в нём ещё нет. Прочитайте её, прежде чем
искать обходной путь для недостающей функции: возможно, она уже в планах. Порядок примерный и может
меняться. Предложить своё можно в [issues на GitHub](https://github.com/WireCatLabs/max-cli/issues).

## Что работает сейчас

Личный аккаунт и боты: чтение, поиск по локальной копии, отправка, группы и каналы, контакты,
задачи, расшифровка голосовых, MCP-сервер для агентов. Полный список команд — на странице
[все команды](commands.md), сценарии — в [рецептах](recipes.md).

## Сейчас в работе

- **Архив вложений.** Скачать вложения в папку с проверкой каждого файла и проверять архив без сети.

## Позже

- **Локальная копия по желанию.** Настройка, с которой `max` ничего не сохраняет на диск и всё
  берёт из MAX.
- **Действия по событию.** Запуск своей команды, когда пришло новое сообщение.
- **Кружки**, **установка и снятие облачного пароля**.
- **Закрепление и архив чатов**, пометка чата непрочитанным.
- **Комментарии в каналах** для личного аккаунта.
- **Установщики** для каждой платформы, без Node и Bun.

Что изменилось в каждой выпущенной версии — в [истории изменений](../CHANGELOG.md).
