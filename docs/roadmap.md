# Дорожная карта

Что планируется в `max`. Порядок примерный и может меняться. Предложить своё можно в
[issues](https://github.com/leemour/max-cli/issues).

## Ближайшее

- **Локальная копия по желанию.** Настройка, с которой `max` ничего не сохраняет на диск и всё
  берёт из MAX.

## Позже

- **Действия по событию.** Запуск своей команды, когда пришло новое сообщение.
- **Кружки**, **установка и снятие облачного пароля**.
- **Установщики** для каждой платформы, без Node и Bun.

Передача сохранённых файлов удалённому агенту реализована: [вложения](attachments.md#файл-для-удалённого-агента).
PDF можно показать постранично как изображения, если клиент агента не открывает исходный файл:
[чтение PDF удалённым агентом](remote.md#читать-pdf-без-сохранения-файла-у-агента).
