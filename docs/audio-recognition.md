# Голосовые сообщения: распознавание речи

Страница нужна, когда в чате MAX пришло голосовое сообщение, а вам или вашему AI-агенту удобнее
прочитать его текстом. После неё вы сможете выбрать модель под язык записи, скачать её один раз
и превратить в текст одно голосовое или все голосовые из списка сообщений.

Несколько слов, которые встретятся ниже:

- **Модель речи** — файл, который переводит звук в текст. Её скачивают один раз, потом она
  работает без интернета.
- **Локальное распознавание** — модель работает на вашем компьютере. Запись не уходит ни во
  внешний сервис, ни к AI-модели агента, и лимиты внешнего API не расходуются.
- **Расшифровка** — готовый текст голосового. `max` сохраняет его, чтобы второй раз не
  распознавать ту же запись.

## Что можно сделать

| Задача | Команда |
| --- | --- |
| Посмотреть модели, их размер и что уже скачано | `max models audio list` |
| Скачать модель | `max models audio download <модель>` |
| Расшифровать одно голосовое | `max messages transcribe <чат> <сообщение>` |
| Расшифровать голосовые в показанном списке | `--transcribe` у `messages list` и `inbox` |
| Выбрать модель для всех следующих запусков | `max config set --defaults transcribeModel <модель>` |

## Быстрый запуск

```sh
max models audio list --json
max models audio download gigaam-v3
max messages transcribe "Учебная группа" 204 --json
```

`max` получает запись из MAX, закрывает соединение и только потом запускает модель.
Модель не скачивается сама во время чтения чата: сначала выполните `models audio download`.
Скачанные файлы используются повторно; при установке их контрольная сумма проверяется.

## Как выбрать модель

| Модель | Для чего подходит |
| --- | --- |
| `gigaam-v3` | Русская речь; модель по умолчанию |
| `gigaam-v3-ctc` | Другой вариант русской модели; текст и его оформление могут отличаться |
| `parakeet-v3` | Речь на нескольких языках, в том числе испанском, английском и русском; занимает больше места и памяти |

Точный размер и что уже скачано, показывает `models audio list`. Выбирайте модель, которая
знает язык записи. Для одного запуска:

```sh
max models audio download parakeet-v3
max messages transcribe "Учебная группа" 204 --model parakeet-v3 --json
```

Для всех следующих запусков:

```sh
max config set --defaults transcribeModel parakeet-v3
```

Не путайте группы команд. `models audio` — модели речи. `models text` — модели для поиска и
ключи API, это другое. Настройка `models.ocr` для картинок на распознавание голоса не влияет.

## Несколько сообщений

```sh
max messages list "Учебная группа" --limit 20 --transcribe --json
max inbox --transcribe --json
```

`--transcribe` обрабатывает только голосовые из показанного списка, у которых ещё нет текста.
Всю историю чата он не трогает. Сначала скачиваются нужные записи, потом закрывается соединение,
потом работает модель. Другую модель на один запуск задаёт `--model`.

Текст сохраняется под вашим аккаунтом в общей локальной копии сообщений. Его видят просмотр
сообщений, входящие, обзор и MCP-сервер. Если то же сообщение уже расшифровано той же моделью,
`max` может вернуть сохранённый текст. В JSON текст лежит в поле `transcript`. Записи, которые
не удалось распознать, перечислены в `unheard`, а причина печатается в stderr.

## Форматы и ограничения

Распознаются голосовые сообщения, которые MAX помечает как `kind: voice`. MP3 или WAV,
присланный как документ, этим путём не расшифровывается, и речь из видео тоже не извлекается.
Для такого файла агенту нужен свой инструмент: например, вынуть звуковую дорожку, перевести
звук в нужный формат и запустить подходящую модель речи.

Локальная расшифровка принимает полную запись Ogg Opus с одним или двумя каналами, до 10 минут.
Более длинную запись сначала разделите на части.

Модели лежат в одной папке для MAX и Telegram; `CLI_COMMON_CACHE_DIR` меняет эту папку.
Скачанной модели нужно место на диске, распознаванию — память и время процессора. Скорость
зависит от длины записи, модели и компьютера.

## Качество

На результат влияют язык, шум, несколько людей, говорящих одновременно, микрофон, темп речи,
имена и редкие термины. Большая модель не всегда лучше для конкретного языка. Важные числа,
имена и договорённости сверяйте с записью. Сохранённый текст не доказывает, что каждое слово
распознано верно.

Агент может прочитать готовый текст и помочь найти ошибки. Чтобы сверить его со звуком, агенту
нужны сама запись и свой инструмент для прослушивания или распознавания — это зависит от агента.

Текст из документов и картинок описан в [руководстве по вложениям](attachments.md).
Как подключить внешнюю модель по API — в [руководстве по внешним моделям](external-models.md).
