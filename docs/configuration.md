# Настройки

`max` настраивается: можно сохранить обычные значения, изменить один запуск или
выбрать другой профиль. Доступ ассистента описан отдельно в [Правах](permissions.md).

## Файл

При первом запуске команды, читающей настройки, инструменты создают `config.json` с обычными
значениями по умолчанию. Существующий файл сохраняется. Посмотреть его путь и текущие значения:

```sh
max config show
```

Файл можно редактировать вручную или командами `config set` и `config unset`. Не храните в
нём данные входа: используйте команды входа и настройки провайдера модели.

| Система | MAX |
|---|---|
| Linux | `~/.config/max-cli/config.json` |
| macOS | `~/Library/Application Support/max-cli/config.json` |
| Windows | `%APPDATA%\max-cli\config.json` |

В PowerShell используйте `max.cmd`. Команды выше покажут фактическое расположение,
если на вашем компьютере выбран другой каталог.

## Три способа задать значение

- **Файл:** значение сохранится для следующих команд. `max config set limit 50` сохраняет лимит результатов.
- **Переменная окружения:** терминал может выбирать профиль или ограничение времени для своей сессии.
  Например, `MAX_PROFILE` выбирает профиль. Не у каждой настройки есть переменная.
- **Параметр команды:** флаг вроде `--limit 5` меняет только этот запуск.

## Какое значение побеждает?

Сначала параметр команды, затем переменная окружения, значение выбранного профиля в файле,
общие `defaults`, встроенное значение. Учитываются только способы, поддержанные конкретной
настройкой. Они перечислены в справочнике мессенджера.

## Короткий пример

```json
{
  "defaults": { "limit": 20, "sendsPerHour": 30 },
  "profiles": { "work": { "limit": 50 } }
}
```

`max work chats list` использует 50. Добавьте `--limit 5`, чтобы получить
пять для одной команды. После удаления значения профиля снова действует общее значение.

## Что можно настроить?

Количество результатов, цвет, запись запусков, лимиты отправки и провайдеров моделей.
[Справочник настроек](configuration-reference.md) перечисляет значения
и способы переопределения. После изменения проверьте результат через `config show`.

## Профили и боты

Профиль хранит настройки аккаунта или бота. Его имя ставится перед командой, например
`max work config show`. Для бота добавьте `bot` после имени.
Подробнее — [Профили и боты](profiles.md).
