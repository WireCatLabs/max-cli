# max

`max` — программа для терминала и MCP-сервер для [MAX](https://max.ru). Она работает с двумя
вещами:

- **с ботом** — через официальный [Bot API MAX](https://dev.max.ru/docs-api), по токену бота;
- **с вашим личным аккаунтом** — как ещё одно ваше устройство, со всеми чатами, историей и
  контактами.

Она сделана для скриптов и ИИ-агентов: одна операция на вызов, один JSON на stdout, понятная
ошибка и постоянный код возврата. Работает в Windows, macOS и Linux.

> ⚠️ **Для личного аккаунта max использует неофициальный внутренний API MAX.** API может
> измениться без предупреждения, а использование может нарушать условия сервиса. Бот работает через
> официальный API, и к нему это не относится.

## Первая минута

```sh
npm install -g @leemour/max-cli
max setup --agent codex                           # QR-вход и навык агента
max chats list --limit 5
max messages send "Иван Петров" "Опаздываю на 15 минут"
```

Настройка может занять около пяти минут. История скачивается отдельно после выбора чата и
объёма. Агент перед входом читает `max skill show`; инструкция доступна без сессии.

С ботом:

```sh
max sales bot auth set                            # токен — в скрытом вводе
max sales bot messages send "Команда продаж" "Сборка готова"
```
