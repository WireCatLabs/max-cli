# max

`max` подключает [MAX](https://max.ru) к терминалу и к вашему ИИ-агенту (например, Claude Code,
Codex, Cursor или Gemini CLI). Она работает с двумя вещами:

- **с вашим личным аккаунтом** — как ещё одно ваше устройство, со всеми чатами, историей и
  контактами;
- **с ботом** — через официальный [Bot API MAX](https://dev.max.ru/docs-api), по токену бота.

Она нужна, когда вы хотите читать, искать и отвечать в чатах без приложения MAX или поручить эту
работу агенту — в границах, которые задаёте вы.

На этой странице — что умеет `max`, как начать за пять минут и какая страница отвечает на какой
вопрос.

Три слова встречаются на каждой странице:

- **Терминал** (командная строка) — окно, где набирают команды: «Терминал» в macOS, PowerShell в
  Windows. `max` — одна команда, которую вы там набираете.
- **ИИ-агент** — программа, которая выполняет задачи за вас и умеет запускать команды, например
  Claude Code или Codex. Он пользуется `max` вместо вас.
- **Навык** (skill) — короткая инструкция для агента о том, как работать с `max`. Настройка ставит
  её сама.

> ⚠️ **Для личного аккаунта max использует неофициальный внутренний API MAX.** API может
> измениться без предупреждения, а использование может нарушать условия сервиса. Бот работает через
> официальный API, и к нему это не относится.

## Что умеет

| Что нужно | Где |
|---|---|
| Читать чаты и непрочитанные сообщения других людей; по умолчанию ничего не отмечается прочитанным | [Личный аккаунт](usage.md) |
| Найти, что было сказано, — по словам, людям, датам, файлам или теме | [Поиск](search.md) |
| Держать копию сообщений на этом компьютере, искать по ней и выгружать её | [Локальная копия](archive.md) |
| Отвечать и отправлять — самому или через агента, в границах, которые вы задали | [Личный аккаунт](usage.md), [Права](permissions.md) |
| Видеть, на какие вопросы в ваших группах никто не ответил и кто вступил | [Группы, которые вы ведёте](groups.md) |
| Вести бота MAX из терминала | [Бот MAX](bot.md) |
| Работать с MAX из приложения без терминала (например, Claude Desktop или Cursor) или из чата в браузере | [MCP-сервер](mcp.md), [ChatGPT или Claude в браузере](remote.md) |

Каждая команда делает одно дело, отвечает всегда в одном виде (один JSON на stdout) и имеет
постоянный код возврата для каждого вида ошибки. Поэтому на неё могут опираться скрипты и агенты.
Работает в Windows, macOS и Linux.

## Начать

```sh
npm install -g @wirecat/max-cli
max setup                 # QR-вход и навык агента
max inbox                 # непрочитанные сообщения других людей во всех чатах
max chats list --limit 5  # пять последних чатов
```

Настройка занимает около пяти минут. Старая история чатов скачивается отдельным шагом. Чтобы
выбрать агента, которому поставить навык, добавьте `--agent` со значением `codex`, `cursor`,
`claude`, `gemini` или `all` (например, `max setup --agent codex`). `max setup --help` показывает
способы входа.

С ботом (`sales` здесь — пример имени профиля бота):

```sh
max sales bot auth set                            # токен — в скрытом вводе
max sales bot api get-my-info --json
```

Для `max` нужен Node 22.16+ или 24+ либо Bun ([что поставить заранее](installation.md#что-нужно)).

Чем `max` отличается от других инструментов — в [README проекта на GitHub](https://github.com/WireCatLabs/max-cli#readme).
