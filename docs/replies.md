# Автоответы

`max serve` может отвечать на входящие сообщения по правилам, которые вы пишете в файл профиля.
Сейчас автоответы работают **только для тестовых аккаунтов**: правило отвечает лишь тем, кто
назван в списке `testers`. Остальным не уходит ничего, даже если правило подходит. Так правила
проверяют на своём втором аккаунте, а не на живых людях.

Каждая команда подробно — [commands.md](commands.md#max-replies).

## Как включить

1. Напишите файл правил `<профиль>.replies.json` в папке настроек — рядом с файлом, который
   `max config show --json` называет в `configFile`. Пример с одним правилом:

   ```json
   {
     "testers": [{ "id": "<id тестового аккаунта>" }],
     "rules": [
       {
         "id": "away",
         "on": true,
         "do": ["reply"],
         "where": { "kinds": ["dialog"], "chats": [], "notChats": [] },
         "when": {
           "hours": { "outside": "09:00-19:00", "days": "mon-fri", "timezone": "Europe/Madrid" },
           "words": [],
           "question": false,
           "mentionsMe": false,
           "from": { "people": [], "notPeople": [], "contactsOnly": false }
         },
         "reply": { "template": "Спасибо, {firstName}! Отвечу утром.", "model": "fill-only", "asReply": true },
         "limits": { "perChat": "1/12h", "perPerson": "1/1d" }
       }
     ]
   }
   ```

   Каждое поле обязательно. Ошибка в имени поля останавливает правило и называет поле.

   Правило можно завести и командами, не открывая файл. `max replies add away` пишет правило со
   всеми полями по умолчанию, выключенным; `max replies edit away --template "…" --outside 09:00-19:00`
   меняет только названные поля; `max replies on away` включает его, если шаблон готов, `off` —
   выключает. `max replies audience` показывает или заменяет, кому и в каких чатах можно отвечать.
   Ошибочная правка не трогает файл. Список `testers` по-прежнему задаётся в файле.

2. Посмотрите, что правило ответило бы на уже сохранённые сообщения — ничего не отправляется:

   ```sh
   max replies test --since-time 7d
   ```

3. Разрешите отправку и запустите сервер:

   ```sh
   max config set permissions.replies.send allow
   max serve
   ```

   Без `allow` сервер не отправляет ничего. Уровень `ask` здесь тоже значит «нет»: у сервера
   некого спросить.

## Что правило не трогает никогда

- ваши собственные сообщения, каналы, ботов;
- сообщение, на которое уже ответили, и изменённое сообщение;
- то, что пришло до запуска `max serve`: после недели простоя он не отвечает на всю неделю;
- в группе — сообщение, где вас не упомянули и не ответили вам, если правило не называет эту
  группу в `chats`.

Лимиты `perChat` и `perPerson` обязательны у каждого правила. Два автоответчика, отвечающих
друг другу, останавливаются на первом лимите.

## Остановить и проверить

- `max replies pause` останавливает все правила профиля сразу, и работающий `max serve` тоже —
  перезапуск не нужен. `max replies resume` включает их снова.
- `max replies status` — разрешена ли отправка, какие правила включены и сколько тестовых аккаунтов
  в списке.
- `max sends list` показывает каждый автоответ с пометкой `rule:<id>` — каким правилом он отправлен.
