# Профили и боты

**Профиль** — имя для одного входа `max` на этом компьютере: личного аккаунта MAX или бота, со
своей сессией и своими настройками. Без имени `max` берёт профиль `default`, поэтому с одним
аккаунтом о профилях можно не думать.

Прочитайте эту страницу, если вам нужен второй аккаунт, если ИИ-агенту нужно меньше прав, чем
вам, или если вы хотите вести бота. В конце вы знаете, как выбрать профиль для команды, как дать
ему свои настройки и как переключиться на бота.

## Что дают профили

| Что нужно | Как |
|---|---|
| Два аккаунта MAX на одном компьютере | Войти один раз в каждый профиль: `max work session start qr` |
| Дать агенту меньше прав, чем у вас | Профиль со своими [правами](permissions.md) |
| Удержать агента в этом профиле | `MAX_PROFILE_LOCK` ([профили во входе и сессиях](sessions.md#профили)) |
| Вести бота MAX рядом с аккаунтом | Профиль бота: `max support bot api get-my-info` |
| Увидеть все профили на этом компьютере | `max account list` |

## Выбрать профиль

Поставьте имя профиля перед командой:

```sh
max work config show
```

`max account list` показывает все профили на этом компьютере и аккаунт каждого;
`max work session end` выводит из MAX профиль `work`.

Запись в `profiles.work` в файле настроек действует для этого профиля; `defaults` применяется,
когда своего значения нет. Правила для имён профилей и порядок, в котором `max` выбирает профиль, —
в разделе [профили во входе и сессиях](sessions.md#профили).

Профиль не является отдельным пользователем ОС: агент с полным доступом к файлам может добраться и
до других данных на этом компьютере.

## Переключиться на бота

Поставьте `bot` после имени профиля:

```sh
max support bot api get-my-info --json
```

Для этих команд нужен уже подключённый профиль бота. Его аккаунт и права определяет MAX, а не ваш
личный аккаунт. [Бот MAX](bot.md) объясняет подключение и примеры.
