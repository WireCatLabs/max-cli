# Профили и боты

Профиль даёт аккаунту или боту имя и отдельные настройки. Он нужен для нескольких аккаунтов,
разных прав ассистентов или работы с ботом.

## Выбрать профиль

Поставьте имя перед командой:

```sh
max work config show
```

Без имени используется профиль по умолчанию. Запись в `profiles.work` действует для этого
профиля; `defaults` применяется, когда своего значения нет. Профиль не является отдельным
пользователем ОС: полный доступ ассистента к файлам может дать ему доступ и к другим данным.

## Переключиться на бота

Поставьте `bot` после имени:

```sh
max support bot api get-my-info --json
```

Для этих команд нужен уже подключённый профиль бота. Его аккаунт и права определяет
мессенджер, а не ваш личный аккаунт. [Боты](bot.md) объясняет подключение и примеры.

## Настройки и доступ

[Настройки](configuration.md) объясняют файл, переменные окружения и флаги.
[Права](permissions.md) определяют действия каждого профиля.
Для входа используйте [инструкцию входа](sessions.md).
