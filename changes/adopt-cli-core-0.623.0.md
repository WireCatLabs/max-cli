### Изменено — может сломать скрипты

- **Собран на cli-core 0.623.0** (был 0.618.0). При первом открытии хранилище переходит на версию 61 (связи людей с
  владельцем, только добавление). Что изменилось между версиями, в
  [журнале изменений cli-core](https://github.com/WireCatLabs/cli-core/blob/main/CHANGELOG.md).
- **`search messages --timeout 30s` ищет до 29 секунд.** Раньше поиск останавливался через 2 секунды, сколько бы
  времени ни дали запуску, и правильный запрос по большому хранилищу падал в WireCat Desktop. Без `--timeout` предел
  остаётся 2 секунды, в том числе для агентов и MCP.
