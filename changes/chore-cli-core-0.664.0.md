### Изменено — может сломать скрипты

- **Агент больше не может удалить чат или очистить его историю через MCP** (cli-core 0.664.0, был 0.662.0). Через
  MCP уровень `ask` проходил без вопроса, и агент мог удалить весь чат из вашего аккаунта MAX, не спросив вас.
  `chats delete` и `chats clear` теперь остаются только в командной строке, где `ask` по-прежнему спрашивает.
- **Списки без `--limit` показывают настроенный `defaults.limit`** (20, если не задан), поэтому `metadata sync` и
  `tags rebuild` берут 20 вместо 50 (cli-core 0.663.0).
- **`models chats show|set allowed|ask|denied`** решает, можно ли отправлять текст чатов модели вне этого компьютера
  (cli-core 0.664.0). При `denied` команды `conversations embed` и `conversations links rebuild --analyze` с такой
  моделью отказываются даже с `--yes`. Ослабить правило может только владелец.

### Исправлено

- **Все флаги времени читают одну грамматику** (cli-core 0.663.0): ISO с секундами и зоной или без них, дата без
  времени, `today`, `yesterday`, `30m`, `2h`, `7d`.
- **`tasks scan`, `conversations embed` и `conversations links rebuild` принимают `yes` через MCP** (cli-core 0.663.0
  и 0.664.0), так что агент больше не останавливается на предпросмотре.
- **`search conversations` отвечает на длинный вопрос по большому хранилищу**: если словесная часть не успела,
  смысловая всё равно отвечает (cli-core 0.664.0).
