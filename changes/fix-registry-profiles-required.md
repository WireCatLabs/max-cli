### Изменено — может сломать скрипты

- **Запись в MCP Registry спрашивает, какие профили обслуживать.** Раньше она запускала `mcp serve --profiles all`, и
  клиент, установивший сервер из реестра, получал все аккаунты на компьютере, хотя владелец их не выбирал. Теперь
  `--profiles` — обязательный аргумент с примером `personal`: клиент спрашивает один профиль, список через запятую
  или `all`. Зачем: CLI никогда не выбирает аккаунт за владельца
  ([WC-MCP-9](https://github.com/WireCatLabs/cli-base/blob/main/docs/standards/mcp.md#wc-mcp-9--a-server-serves-the-profiles-it-is-told-with-one-connection-for-each)). Обратите внимание: клиент, настроенный по старой записи, оставит `--profiles all`, пока его не
  настроят заново; сервер, добавленный вручную или через `mcp config`, не меняется.
