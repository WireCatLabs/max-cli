### Что нового

- **Навык для агентов стал почти в восемь раз короче**: `SKILL.md` — около 9 КБ вместо 71 КБ, то есть примерно
  2 200 токенов в каждом ходе агента вместо 17 000. В нём остались профиль, главные задачи, границы и форма
  вывода. Остальное — поиск, отправка, бот, MCP, вложения, статистика и прочее — лежит в
  `skills/max-cli/references/`, и `SKILL.md` говорит, когда какой файл читать. Ни одно правило не пропало.
- **`max skill install` ставит всю папку навыка**, вместе с `references/`, а `max skill show <имя>` печатает один её
  файл (`max skill show search`) — для агента, который прочитал навык без папки.
