### Изменено — может сломать скрипты

- **`max` собран на cli-core 1.0 и cli-base 1.0.** Хранилище при первом открытии переходит на версию 73: номер
  записи больше никогда не выдаётся дважды, а открыть хранилище после этого могут только инструменты на cli-core 1.0.
  Обновите все установленные CLI WireCat до запуска этой версии. Перед переходом пишется копия для отката. Без неё
  переход не начинается.
- **Вызов через MCP, который называет запрещённое место, отвечает `permission_error`**, а не `validation_error`.
  Перед каждым вызовом через MCP каждая опция и аргумент с локальным файлом или папкой проверяются по настоящему пути:
  вызов не может назвать папку с ключами, папку инструмента WireCat или хранилище. Запуск в терминале не меняется.
- **`schedule exec` больше не доступен через MCP.** Он запускает только файл расписания из своей папки расписаний.
  Агент запускает сохранённое расписание через `schedule run <name>`.
