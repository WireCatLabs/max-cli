### Изменено — может сломать скрипты

- **Уровень `readonly` больше не останавливает синхронизацию** (cli-core 0.662.0, был 0.659.0). Команды, которые
  только забирают данные из MAX в локальное хранилище (`sync`, `messages sync`, `contacts sync`, `metadata sync`,
  `store gaps repair`, `--sync-first`), работают при `readonly`; `deny` по-прежнему их запрещает. Команды, которые
  пишут файлы владельца или обращаются к другому сервису, `readonly` по-прежнему останавливает. Если профиль
  полагался на `readonly`, чтобы не синхронизироваться, задайте ключу `deny`.
- **Даты в запросах списков читаются в часовом поясе компьютера** (cli-core 0.661.0). `today` и дата без времени в
  `tasks list`, `chats list` и других списках начинались в UTC, теперь начинаются в местную полночь, как в поиске.
- **MCP-инструмент `messages_photo` принимает `attachment`, начиная с 1** (cli-core 0.661.0), как `attachments_show`.
  Раньше он принимал `index` с 0.
- **Поиск на сервере больше не отправляет человека из `to:` или `cc:` как отправителя** (cli-core 0.660.0);
  хранилище по-прежнему фильтрует по ним.
